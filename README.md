# 🍔 Food Ordering Website

A responsive and interactive food ordering website built using **HTML**, **CSS**, and **JavaScript**. This project simulates a basic food delivery interface, allowing users to browse food items, add them to a cart, and place an order.

## 🚀 Features

- 🖼️ Homepage with featured items and categories
- 🛒 Add to cart and remove items functionality
- 📱 Fully responsive design (mobile-first)
- 🔍 Search/filter food items
- 💡 Interactive UI with animations
- 🧾 Simple order summary and confirmation

## 🛠️ Tech Stack

- **Frontend**:  
  - HTML5  
  - CSS3 (Flexbox/Grid, Media Queries)  
  - JavaScript (DOM Manipulation, Events
